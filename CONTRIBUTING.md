# Contributing to AI Image Detector

Thank you for your interest in improving the AI Image Detector project! 🎉

## How Can I Contribute?

### Reporting Bugs
- Ensure the bug was not already reported by searching existing GitHub Issues.
- Open a new issue with a clear title and description.
- Include details about your operating system, Python version, error tracebacks, and steps to reproduce.

### Suggesting Enhancements
- Open an issue describing your proposed feature or improvement.
- Explain why this enhancement would be useful to other users.

### Pull Requests
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes and verify that everything runs cleanly:
   ```bash
   python test_classify.py
   ```
4. Commit your changes with clear, descriptive commit messages:
   ```bash
   git commit -m "Add new prompt ensembling strategies"
   ```
5. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
6. Submit a Pull Request targeting the `main` branch.

## Code Style & Standards
- Maintain clean, readable, and well-commented Python / JavaScript / CSS code.
- Ensure all API routes return structured JSON responses with appropriate HTTP status codes.
- Do not commit large binary files (`.pt`, `.pth`, etc.) directly to the repository.

Thank you for contributing! 🚀
